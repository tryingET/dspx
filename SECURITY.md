Security Policy
===============

Reporting a Vulnerability
-------------------------
Please report security issues privately. Open an issue with minimal details and request a secure contact channel, or email the maintainers if listed. We will coordinate a fix and disclosure timeline.

Scope
-----
This project’s source code and release artifacts.

Disclosure
----------
We aim to acknowledge reports within 3 business days and provide regular status updates until the issue is resolved.
